# 모션카 — 중고차 숏폼 메이커

중고차 사진과 정보를 입력해 짧은 세로 영상을 만드는 한국어 웹 앱입니다.

## 3단계 제작 흐름

1. 사진 3~10장을 추가하고 순서를 정합니다. 첫 사진이 영상의 첫 장면이 됩니다.
2. 차량명, 연식, 주행거리, 가격, 매물 번호, 매장 정보와 문구를 입력합니다.
3. 영상 스타일과 비율·길이를 고르고 WebM을 만들어 기기에 저장합니다.

## 기능

- 사진 드래그 앤 드롭, 개별 삭제와 순서 변경
- 세 가지 무드, 네 가지 비율, 8·12·20초 영상
- 사진에 느린 카메라 이동과 차량 정보, 자막, 끝 카드를 합성
- 브라우저에서 바로 영상 인코딩 및 다운로드
- 업로드 사진은 서버로 전송하지 않음

별도 설치 없이 최신 Chrome 또는 Edge에서 사용할 수 있습니다. 현재 영상은 Canvas/MediaRecorder로 브라우저에서 생성하며, 외부 AI 영상·음성 생성, 음악 제공, 이메일 발송, SNS 자동 게시 기능은 연결되어 있지 않습니다.
