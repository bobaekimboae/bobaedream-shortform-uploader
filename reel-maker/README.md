# 모션카 — 중고차 숏폼 메이커

중고차 사진과 차량 정보를 넣어 짧은 영상을 만드는 한국어 웹 앱입니다.

## 사용 방법

최신 Chrome 또는 Edge에서 [앱 열기](./index.html)를 누른 뒤 사진을 추가하고 스타일, 비율, 길이를 선택하세요. 차량 정보와 자막을 입력하고 `영상 만들기`를 누르면 WebM 영상이 다운로드됩니다.

## 포함 기능

- 차량 사진 최대 9장 추가, 드래그 앤 드롭, 대표 사진 선택 및 삭제
- 6가지 스타일, 4가지 비율, 8·12·20초 영상 길이
- 차량명, 연식, 주행거리, 매물 번호, 가격, 매장 정보 및 자막 입력
- Canvas와 MediaRecorder를 이용한 브라우저 내 영상 생성
- 업로드한 사진은 서버로 전송되지 않음

현재 영상은 사진의 움직임과 입력 문구를 조합해 브라우저에서 생성합니다. 외부 AI 영상 생성 API는 연결되어 있지 않습니다.
