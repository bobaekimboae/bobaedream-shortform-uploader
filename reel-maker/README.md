# 모션카 — 중고차 숏폼 메이커

중고차 사진과 매물 정보를 조합해 유튜브 쇼츠·인스타그램 릴스용 세로 영상을 만드는 한국어 웹 앱입니다.

## 사용 방법

1. [모션카 웹 앱](https://bobaekimboae.github.io/bobaedream-shortform-uploader/reel-maker/)을 Chrome 또는 Edge에서 엽니다.
2. 차량 사진 3~10장을 추가하고 첫 장면이 될 사진을 맨 앞으로 정렬합니다.
3. 차량명, 연식, 주행거리, 가격과 매장명 등 영상에 넣을 정보를 입력합니다.
4. 영상 스타일, 화면 비율과 길이를 고릅니다. 9:16, 8·12·20초를 지원합니다.
5. MP4 영상 만들기를 누릅니다. 완성된 결과를 미리보기로 확인하고 MP4 파일을 사용합니다.

## 제공 기능

- JPG, PNG, WebP 사진 업로드, 드래그 앤 드롭, 순서 변경 및 삭제
- 3가지 스타일과 차량 정보·자막·끝 카드 합성
- 9:16 등 여러 비율 및 8·12·20초 설정
- 브라우저에서 H.264 MP4 영상 생성 및 다운로드 (WebCodecs 사용 가능 브라우저)
- 인코더를 쓸 수 없을 때 WebM 내보내기 대체 경로
- 업로드 사진을 서버로 전송하지 않는 기기 내 처리
- 완성 영상의 앱 내 미리보기

## 기술 및 제한

정적 웹 앱으로 GitHub Pages에서 제공됩니다. 영상은 사용자의 브라우저에서 생성됩니다. H.264 MP4 인코딩은 Mediabunny 1.65.0을 jsDelivr에서 불러와 사용하며, WebCodecs 및 기기의 H.264 인코더 지원이 필요합니다. 첫 MP4 생성 시 인터넷 연결이 필요합니다. 인코더 지원이 없으면 WebM으로 저장되며, 이 파일은 Instagram 업로드용으로 보장되지 않습니다.

AI 음성·생성형 영상, 배경 음악 라이선스, 계정 로그인, 이메일 발송 및 SNS 자동 게시 기능은 포함하지 않습니다. 제작한 영상은 SNS에 직접 업로드할 수 있습니다.

## 개발

별도 빌드 단계가 없는 정적 페이지입니다. Python이 설치된 환경에서 저장소 루트로 이동하여 python -m http.server 5179를 실행한 뒤 http://127.0.0.1:5179/work/usedcar-reels-kr/를 엽니다. 실제 배포 파일은 저장소의 reel-maker/index.html입니다.
