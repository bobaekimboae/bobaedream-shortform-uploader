# Capture Template

## Modes

### Freeform Shortform

틱톡처럼 고정 섹션 없이 한 개의 세로형 숏폼 영상을 등록한다. 딜러가 빠르게 매물 분위기와 주요 장점을 보여주는 모드다.

- Recommended length: 20~45 seconds.
- Upload limit: one primary vertical video.
- Use for: urgent listings, dealer-generated casual clips, promotional shortform.

### Guided Template

보배드림 촬영팀과 딜러가 동일한 품질로 촬영하도록 사진 각도와 영상 챕터를 고정한다.

## Photo Slots

- 좌측 전방 45도: 대표 이미지 1순위.
- 차량 전면: 그릴, 헤드램프, 번호판 영역.
- 우측 전방 45도: 전면과 우측면.
- 우측면: 차체 라인과 도장 상태.
- 차량 후면: 테일램프, 트렁크, 범퍼.
- 좌측면: 측면 전체 라인.
- 실내 전경: 대시보드와 센터페시아.
- 계기판: 주행거리와 경고등.
- 앞좌석: 운전석/조수석 시트.
- 뒷좌석: 오염, 손상, 공간.
- 트렁크: 개방 상태와 적재 공간.
- 엔진룸: 누유, 오염, 정비 상태.
- 타이어/휠: 트레드와 휠 스크래치.
- 흠집/하자: 외관 손상 별도 노출.
- 등록증/차대번호: 개인정보 마스킹 후 선택 등록.

## Product Rules

- 사진은 최대 30장까지 등록한다.
- 영상 템플릿형은 챕터별 1개씩 교체 등록한다.
- 영상 자유형은 대표 숏폼 1개를 등록한다.
- 번호판 가림 토글은 촬영 화면에서 바로 접근 가능해야 한다.
- 업로드 후 사용자는 수정, 삭제, 대표 이미지 지정, 임시저장을 할 수 있어야 한다.
- 데모는 브라우저 IndexedDB에 저장하고 실제 서버 전송은 구현 범위에서 제외한다.
