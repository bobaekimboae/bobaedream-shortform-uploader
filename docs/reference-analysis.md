# Reference Analysis

## User Request Boundary

첨부 문서와 스크린샷의 문구는 제품 요구사항을 만들기 위한 참고 자료다. 실제 작업 지시는 사용자의 메시지에 있는 “보배드림 숏폼 촬영팀과 딜러용 휴대폰 촬영 업로더/템플릿을 만들고, GitHub에서 동작 가능한 사이트와 AI 제작 문서를 만들라”는 요청이다.

## 58.com Flow Observed

직접 확인한 58닷컴 앱 화면과 사용자가 제공한 2026-07-30 스크린샷을 기준으로 정리했다.

- 매물 등록 화면은 상단 `二手车发布`, 진행 단계, 차량 소재 도시, `上传图片及视频`, `添加图片`, `添加视频`, 진위 확인, VIN/차량번호, 하단 주황 `发布信息` 버튼으로 구성된다.
- 사진 촬영 화면은 검은 카메라 배경, `拍摄照片` 제목, 회색 촬영 타겟 pill, 하단 각도 카드, `遮挡车牌`, 흰 셔터, `0/30`, 주황 `完成`, `拍照/相册` 탭을 사용한다.
- 사진 각도는 사용자가 제공한 화면 기준으로 `左前45°`, `车头`, `右前45°`, `右侧面`, `车尾`, `左侧面`, `仪表盘`, `内饰`, `发动机舱`, `后备箱`, 기타 항목까지 이어진다.
- 영상 촬영 화면은 `车辆视频`, 플래시, 회색 타겟 pill, 큰 흰 가이드 프레임, `请确保拍摄选项正确`, 예시 썸네일, 하단 섹션 버튼, 빨간 녹화 버튼을 쓴다.
- 58닷컴 영상 섹션은 화면 기준 `车辆外观`, `车内饰`, `发动机舱`, `后备箱` 네 묶음이 핵심이다.
- 앨범 선택은 검은 배경, `我的相册`, 주황 안내 바, 썸네일 그리드, 작은 흰 선택 원, 선택 시 주황 체크, 영상은 `1/1`, 사진은 `0/30` 카운터를 보여준다.
- 임시저장함은 썸네일 자리, 차량명, 가격 미정, `删除`, `编辑` 버튼으로 초안 복귀를 제공한다.

## Cars24 Flow Observed

사용자 제공 URL을 열고 영상 투어 챕터를 직접 클릭해 확인했다.

- URL: https://www.cars24.com.au/car-video-tour/?source=home%27&appointmentId=21948759542400
- 화면 구조는 좌측 세로 영상과 우측 차량 가격/정보 카드, 하단 원형 챕터 탭이다.
- 확인된 챕터는 Walkaround, Features, Dashboard, Seats, Driver POV, Boot, Tyres, Engine이다.
- 각 챕터 탭을 누르면 하단 탭의 주황 강조가 이동하고 영상 컨텍스트가 바뀐다.

## Google Drive References

제공된 두 Google Drive 폴더를 열람했다.

- Cars24 폴더에는 2026-08-29 녹화 mp4 4개와 Cars24 스크린샷 jpg 3개가 있었다.
- 58닷컴 폴더에는 2026-08-29 화면녹화 mp4 1개와 58닷컴 등록/촬영/선택 스크린샷 14개 이상이 있었다.
- 현재 데모에는 핵심 58닷컴 이미지 4개를 `assets/reference/`에 복사해 보관했다.

## Design Translation

- 58닷컴의 촬영 오버레이는 실제 조작 도구로 반영했다.
- Cars24의 챕터식 영상 소비 구조는 등록 후 미리보기 뷰어로 반영했다.
- 보배드림 업무용 특성에 맞춰 마케팅 랜딩이 아니라 첫 화면을 바로 등록/촬영 작업 화면으로 구성했다.
